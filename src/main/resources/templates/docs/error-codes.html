성공 응답 HTTP 200

{
  "success": true,
  "code": "200",
  "message": "...",
  "data": { ... }
}
  • 조회·생성·수정·삭제 모두 HTTP 200 (201을 쓰지 않음)
  • 돌려줄 데이터가 없는 API는 data가 null

에러 응답 HTTP 4xx · 5xx

{
  "success": false,
  "code": "AUTH_001",
  "message": "...",
  "data": null
}
  • 분기는 code로, message는 화면 표시용
  • HTTP 상태는 아래 표의 HttpStatus
